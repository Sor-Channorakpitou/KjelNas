# KjelNas

**Feeling lazy? Just 5 minutes.**

KjelNas ("so lazy") is a gentle anti-procrastination app. Procrastination is
avoiding a bad feeling, not laziness — so KjelNas makes starting tiny, shows
only the next step, and celebrates starting, not just finishing.

Fully offline. No account needed.

## Run it

Requires [Flutter](https://docs.flutter.dev/get-started/install) (stable).

```bash
flutter pub get
flutter run -d chrome
```

## Tech

fl_chart · Nunito (google_fonts)
